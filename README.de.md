# ProtectedAction

Deutsch | [English](README.md)

IP-Symcon-Bibliothek von Ueli Schweizer / Cassanis Automation.

| Modul | Beschreibung |
|---|---|
| [ProtectedAction](ProtectedAction/README.de.md) | HTML-Kachel, die hinterlegte Aktionen nach Eingabe einer PIN oder eines Musters ausführt |

## Voraussetzungen

IP-Symcon ab Version 8.1 mit der PHP-Erweiterung Sodium. Ab 9.1 kann die Kachel
zusätzlich im Vollbild-Modus angezeigt werden.

## Installation

Über den Module Store oder im Module Control mit der URL
`https://github.com/wowbagger60/ProtectedAction`.

## Unterstützung

Dieses Modul ist kostenlos. Schenkungen als Unterstützung für den Autor werden
