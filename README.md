# ProtectedAction

[Deutsch](README.de.md) | English

IP-Symcon library by Ueli Schweizer / Cassanis Automation.

| Module | Description |
|---|---|
| [ProtectedAction](ProtectedAction/README.md) | HTML tile that runs stored actions after a PIN or pattern has been entered |

## Requirements

IP-Symcon 8.1 or later with the PHP extension Sodium. From 9.1, the tile can
also be shown in fullscreen mode.

## Installation

Via the Module Store, or in Module Control with the URL
`https://github.com/wowbagger60/ProtectedAction`.
